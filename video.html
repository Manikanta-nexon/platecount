Common questions

Do guests need to install an app?

No. They just tap the link in WhatsApp.

Does it send WhatsApp messages by itself?

Not yet. The host taps the WhatsApp button for each guest. We may add automatic sending later.

What if a guest changes plans?

They open the same link again and send a new answer. The host always sees the latest one.

Who can see my guest list?

Each guest link is private to that guest, and each host can see only their own weddings.

Does it work for other functions?

Yes, for any function with a guest list, like an engagement or a housewarming.
